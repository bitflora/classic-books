# classic-books
I read a lot of classics. Some of them are challenging to read for a variety of reasons. This is a catch-all bucket for those that I have enhanced in some way.

Right now there's only one.

## Tristram Shandy
This rambling Great Book can be difficult to read due to the lack of clear punctuation and quotation marks telling you who is talking. I had LLMs punctuate it for me, which made it much easier to read for me. The text is otherwise untouched.

It is originally sourced from Gutenberg.
